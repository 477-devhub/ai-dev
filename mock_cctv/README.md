추가 유료 분석을 접수하지 않습니다. 새로고침에서는 이 탭의 접수된 작업 ID를 복원합니다.
별도 새 탭에서는 새 분석을 접수할 수 있으므로 진행 중에는 기존 시연 탭을 사용하세요.

프론트 `public/mock-cctv-media/`에 배치했으며 Git에서 제외합니다.

## 기존 백엔드/프론트 연결

목업 전용 모드도 백엔드의 `MEDIA_ROOT/CAM_XX.mp4` 규칙에 맞췄습니다. 다른 백엔드가 8000 포트를
사용하고 있다면 먼저 해당 서버를 종료한 뒤 아래 명령으로 실행합니다.

```powershell
& D:\projects\477\mock_cctv\start-backend.ps1
```

이 스크립트는 현재 PowerShell 세션의 MEDIA_ROOT, ASSET_ROOT, ASSET_MAP,
DEMO_SCENARIO_PATH를 설정하고 기존 `D:\projects\477-backend`를 실행합니다.
백엔드 파일을 수정하지 않습니다. 다른 위치/인터프리터는 `-BackendRoot`, `-PythonPath`로 지정합니다.
기존 프론트에서 백엔드 연결 모드를 사용하면 `/stream/CAM_01`~`/stream/CAM_09`로 재생됩니다.
프론트의 오프라인 스틸 목업 모드는 영상 스트림을 사용하지 않습니다.

`demo-scenario.json`에는 사건을 넣지 않았습니다. 따라서 기본 합성 사건/위험도 예시가
새 영상에 대한 AI 판정으로 표시되지 않습니다. CAM_01/02의 실제 시간 보정도 하지 않았습니다.

`asset-map.json`은 카메라별 입력 토큰을 제공합니다. CAM_03은 교체 전 분석 결과와 구분하기 위해 `MOCK_CLIP_03_V2`를 사용합니다. 매핑 변경 후 백엔드를 재시작해야 합니다.
분석 요청에는 camera_id와 해당 clip_ref, 영상 길이 안의 start_ms/end_ms를 사용합니다.
영상 재생만으로 AI 분석은 실행되지 않습니다.
