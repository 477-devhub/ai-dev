# 실제 녹화 영상 관제 시연

AI 데이터 프로젝트 `D:/projects/477/mock_cctv/README.md`에 실행과 영상 준비 방법이 있습니다.

백엔드는 `start-backend.ps1 -Analyze`로 development/cascade_v1을 실행합니다.
프론트는 API 모드의 상단 `관제 시연 재생` 버튼으로 9개 영상과 분석9건을 시작합니다.
CAM03은 추가 제공된 사건8-대로일상.mp4입니다. 현재9개는 서로 다른 원본이며 모두 분석 입력으로 등록합니다. 서로 다른 시점의 자동 사건 병합은 없습니다.

화면은 public/mock-cctv-media/CAM_01.mp4~CAM_09.mp4의 360p 녹화 사본을 사용하고,
AI는 별도 등록된1080p 입력을 사용합니다. 재생본은 원본 시간축과 길이를 보존하며 무음입니다.
각 영상 끝에서 정지하고, 최장35초 후에는 진행 중인 AI 결과를 기다립니다.
실제 결과는 기존 API/WebSocket 경로의 사건·검토·제외 목록으로 표시합니다.
카메라별 접수/준비/CV/P1/P4/완료/실패는 상단 진행 상황에서 확인합니다.
모델 처리 시간은 영상 길이와 다르며 현재 작업 워커는 순차 실행합니다.

일시정지·처음으로·다시재생은 추가 분석을 접수하지 않습니다.
접수한 작업과 Idempotency-Key는 이 탭의 sessionStorage에 보존해 새로고침에서 복원합니다.
서버 재시작으로 작업이 없어지면 오류를 표시합니다. 별도 새 탭은 새 분석을 접수할 수 있습니다.
`?analysis=off`는 새 분석 요청 없이 영상을 재생하고 기존 서버 결과만 확인하는 모드입니다.
API 키는 백엔드 환경에만 두며 프론트 번들에 포함하지 않습니다.

검증: npm run build, npm test(24PASS), 9개 Vite→FastAPI HTTP206,
실제 분석9건 접수와 실제 모델 결과의 카드·위험도 표시,
Chrome 9개 영상 끝까지 재생/자동정지 확인.
기존 로컬 fixture 테스트와 실제 관제 시연은 별도 모드입니다.
